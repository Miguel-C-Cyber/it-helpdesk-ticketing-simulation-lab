\# LakeAve Health Systems Environment Overview



\## Organization

LakeAve Health Systems is a fictional healthcare organization created for IT support and cybersecurity portfolio simulation purposes.



\## Simulated IT Environment

The environment simulates a small-to-mid sized healthcare support infrastructure including:

\- Remote VPN access

\- Microsoft Office 365 services

\- Outlook email support

\- Employee workstation support

\- Basic security monitoring workflows



\## Support Scope

This project simulates Tier 1 IT Service Desk responsibilities including:

\- Ticket intake and triage

\- User support and troubleshooting

\- Incident escalation

\- Service request fulfillment

\- Documentation and communication workflows



\## Platform Used

\- Freshdesk cloud help desk platform
